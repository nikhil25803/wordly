# wordly
Wordly is a simple terminal-based word guessing game where everyone around the world gets the same word each day. No accounts, no servers, and no package managers — just install it with a single curl command and run wordly from your terminal.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/nikhil25803/wordly/main/install.sh | sh
```

The installer supports macOS, Linux, and Windows from a POSIX shell such as Git Bash. It installs to `~/.local/bin` by default; set `WORDLY_INSTALL_DIR` to choose another directory.
